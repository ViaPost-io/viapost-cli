# Security policy

## Supported versions

Only the latest `0.1.x` release receives security fixes while the CLI is in beta.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private security advisory flow for this repository or contact the ViaPost security team through the support channel published at https://viapost.io.

Never include real API keys, message bodies, recipient data, or production logs in a report. Revoke any credential that may have been exposed.
